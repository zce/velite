# Remove comments without dropping surrounding content

Status: ready-for-agent

Created: 2026-07-16T02:25:18Z

## Problem

The Markdown comment-removal transform removes an entire mdast HTML node whenever that node contains an HTML comment. Content surrounding the comment inside the same node is lost. The MDX transform similarly removes an entire flow expression when it contains a block comment and does not cover text expressions.

Example: `<div><!-- secret --><span>keep</span></div>` can be removed completely instead of preserving the non-comment markup.

Evidence: `src/core/content/markdown.ts` and `src/core/content/mdx.ts` splice the whole child node after a regex match.

## Expected behavior

Remove only comment syntax and preserve all non-comment content, with explicit behavior for block and inline Markdown/MDX forms.

## Design context

Ordering and mutation isolation are being decided in [Define plugin execution and isolation semantics](06-define-plugin-execution-and-isolation-semantics.md).

## Answer

> _This was generated by AI during triage._

**Verification:** Confirmed. `src/core/content/markdown.ts` removes an entire `html` node whenever its value contains an HTML comment. `src/core/content/mdx.ts` likewise removes an entire `mdxFlowExpression` containing a block comment and does not visit `mdxTextExpression`.

**Disposition:** `implementation-constraint`.

**Design coverage:** Decision 06 keeps the comment-removal transforms as ordinary plugin behavior and explicitly requires them to preserve unrelated content; the architecture does not otherwise eliminate this logic.

**Implementation constraint:** The comment-removal transforms in `src/core/content/markdown.ts` and `src/core/content/mdx.ts` (or their 1.0 equivalents) must remove only comment syntax. Markdown HTML nodes must retain all surrounding HTML. MDX must cover both block and text expression forms while preserving every non-comment JSX or expression fragment in the affected node.

**Acceptance test:** Process `<div><!-- secret --><span>keep</span></div>` as Markdown and assert that the result retains `<div><span>keep</span></div>` with no comment. Add MDX fixtures for both `mdxFlowExpression` and `mdxTextExpression` containing a block comment alongside non-comment content; assert that only the comment is removed and the remaining content still compiles. This test enforces decision 06.
