- [x] Retain dependency/runtime versions, workload/options, resulting values, stage observations, elapsed measurements, and process memory/retention observations sufficient to explain material changes. Do not infer a universal plugin concurrency or memory guarantee from selected workloads.
- [x] Investigate and address material correctness/ownership regressions within this feature before acceptance; explain remaining measured tradeoffs. Do not invent a percentage threshold, GC-timing assertion, statistics API, benchmark dashboard, or the older broad release-gate infrastructure.
- [x] Complete Standards and Spec review of the integrated change against the fixed pre-implementation point. Review must cover active repository conventions, accepted ADR/contract, all parent requirements, explicit limitations, and removal of temporary coexistence.

- [x] Run `pnpm build` followed by `pnpm test`, including packaged and consumer-type checks, and record the actual result rather than claim coverage from source-only tests.
