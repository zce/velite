# @velite/plugin-next

A Next.js plugin for integrating Velite content processing.

## Installation

```bash
npm install -D velite @velite/plugin-next
```

## Usage

```ts
// next.config.ts
import { withVelite } from '@velite/plugin-next'

export default withVelite({
  // other next config here...
})
```
